## ✨ Features

- 📄 **ATS Resume Analyzer**: check how well your resume performs against applicant tracking systems
- 🎯 **Resume vs Job Description Match**: see how closely your profile fits a specific role
- 📝 **AI Resume Optimizer**: get AI-driven improvements to your resume content
- ✍️ **Personalized Cover Letter Generator**: tailored cover letters for each application
- 🎙️ **AI Mock Interview**: practice HR and technical rounds
- 🤖 **AI Career Coach**: guidance on your job search and career path
- 📊 **Job Finder**: discover relevant job openings

## 🛠 Tech Stack

| Area | Technology |
|------|------------|
| Framework | Next.js (App Router), React, TypeScript |
| Styling | Tailwind CSS, Framer Motion |
| Database & Auth | Supabase (PostgreSQL, Authentication, Row Level Security) |
| AI | AI APIs for resume analysis, job matching and content generation |
| File handling | pdf-parse, mammoth, jsPDF |
| Deployment | Netlify with GitHub CI/CD |

## 🚀 Getting Started

```bash
git clone https://github.com/anujkm0708/interview-boost-ai.git
cd interview-boost-ai
npm install
npm run dev
```

Open http://localhost:3000

## 🔐 Security

User data is protected with Supabase authentication and Row Level Security, so users can only access their own records.
