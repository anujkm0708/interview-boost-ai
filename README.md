# 🎯 Interview Boost AI

An AI-powered interview preparation app that helps you practice questions, get instant feedback, and walk into interviews with confidence.

![Next.js](https://img.shields.io/badge/Next.js-black?logo=next.js)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Features

- 🤖 **AI-generated questions**: role-specific technical and behavioral questions on demand
- 📝 **Instant answer feedback**: get scored and receive suggestions on clarity, structure and depth
- 📄 **Resume-based practice**: questions tailored to your own experience and skills
- 🎭 **Mock interview mode**: simulate a full interview round from start to finish
- 📊 **Progress tracking**: review past sessions and see where you're improving
- 📱 **Responsive UI**: works on desktop and mobile
- ⚡ **Fast deployment**: hosted on Vercel

## 🛠 Tech Stack

- Next.js, React, TypeScript
- (AI API / database / auth you use)

## 🚀 Getting Started

```bash
git clone https://github.com/anujkm0708/interview-boost-ai.git
cd interview-boost-ai
npm install
npm run dev
```

Open http://localhost:3000
